## Hi there 👋

또한 고객 기술지원 업무를 통해 원활한 커뮤니케이션 스킬을 배워왔으며, 운영 현황 및 장애 처리 내용을 공유하며 협업 기반의 업무 수행 능력을 갖추고 있습니다.
</p>
